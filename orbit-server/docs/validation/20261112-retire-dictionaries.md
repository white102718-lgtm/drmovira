# 产品、总代业务字典退役（2026-11-12）

## 变更范围

- 业务字典页面仅保留户商，移除产品/总代类别、模板字段、筛选及候选请求。
- 渠道列表、详情、创建、编辑移除产品与总代；归属团队、分配用户、渠道 ID、名称、类型、媒体、链接、状态保留。
- 渠道写入合同不再接受 `product_id` / `agent_id`；旧客户端需刷新。已有渠道读取和幂等重放过滤退役字段，编辑/分配/停用清除旧 JSON 字段，不再受历史产品锁限制。
- 创建广告仍验证渠道启用状态、调用者和目标投手权限及归属，但不再依赖产品/总代记录、可用状态或关联关系。
- PRODUCT / BUSINESS_AGENT 列表、新预检、旧预检读取与提交均返回 HTTP 410 `REFERENCE_KIND_RETIRED`。不能通过旧待提交任务恢复已移除的字典。
- 户商的预检、提交、拥有者范围和账户引用保持原合同。AdsPower 的设备 Agent ID 与总代不同，未改动。

## 数据兼容与部署

先执行 `orbit-server/python/orbit_api/migrations/078_retire_product_agent_dictionary.sql`，使旧渠道两个引用列可为空，再部署应用。保留旧列、引用记录和审计记录用于历史追溯，不进行不可逆的历史数据删除。原冻结 PRD / OpenAPI 基线作为历史文档保留，本说明描述当前渠道合同的变更。

服务端发布目录：`/opt/orbit/releases/20261112-retire-dictionaries`。
部署前备份渠道/字典/导入/时钟表以及 API、Nginx 配置；旧静态资源保留，兼容已打开浏览器。数据库迁移向后兼容；应用回退后，新建无产品渠道无法用旧版编辑，因此若回退须先恢复本版或安排维护，不将历史恢复 SQL 当作无损回退。
