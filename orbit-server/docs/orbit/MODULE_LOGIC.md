> 当前技术覆盖：RuoYi-FastAPI/Python + MySQL8 + Redis，全部功能重新开发。下文历史Java实现描述仅供核对，旧PASS不计新版本通过。现行方案见[IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)，状态见PROGRESS.md。
本文件描述待实现的完整行为，不代表功能已完成。每个编号分别跟踪开发、测试、验收，实际勾选见 [PROGRESS.md](PROGRESS.md)。字段原文见 [FIELD_MATRIX.md](FIELD_MATRIX.md)，接口操作见 [API_MATRIX.md](API_MATRIX.md)。

需求来源为 `baseline/PRD-ORBIT.md`、`baseline/CONTRACT_OVERRIDES.md`、`baseline/contracts/`，正文补充信息和原型交互同样属于核对范围。优先级：用户最新要求 > PRD/覆盖表 > 当前合同 > 保留业务合同 > 历史参考。以下清单用于组织实施，不能替代完整原合同；发现额外交互时必须补充条目，不能以清单暂未登记为由省略。
