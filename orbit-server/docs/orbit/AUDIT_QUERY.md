# 范围冻结审计内部查询

当前是ScopeFreezeAuditQuery.scanTrusted(target, filter, size, cursor)内部服务。没有公开控制器、审计路由或页面，不是原合同完整AuditPage响应，也不代表其他业务审计已经接入。

## 字段与授权

- target仅在当前ServerTenantScope启用租户集合内有效。USER、TEAM_ADMIN仍限定当前home；SUPER_ADMIN可内部逐个查询当前启用目标。完整跨租户合并查询及其单个scope_version语义尚未接入，不能用SUM/MAX冒充。
- 每批先验证当前会话、ORBIT父菜单/系统父菜单/system.audit.read动作的有效功能角色并集，再逐条调用审计读取核心验证本人、历史团队与当前管理团队、原快照及当前成员可见性。
- 候选不等于已授权。不可见候选在读取服务的事务代理返回之前转换为空；不得跨代理抛404后在外层捕获，否则Spring会把整批标记rollback-only。功能权限/会话等错误仍正常抛出，不能当作空结果。
- 旧actor_subject_id、actor_team_id、request_id保持NULL，不补造业务UUID或请求UUID。内部Entry保留历史未知；后续公开Audit契约适配仍需明确处理，不静默丢弃旧历史。

## 筛选

| 输入 | 实际逻辑 |
| --- | --- |
| q | NFC规范化，去首尾普通空白，最多100码点，拒绝控制字符；只匹配action代码的字面子串，SQL转义!、%、_，不查请求原文或账户外部ID |
| operator | 严格规范UUID，精确匹配事件发生时actor_subject_id，人员当前映射不改写历史；未知字段无法匹配 |
| dateFrom/dateTo | 严格ISO日期；以事件UTC日为准，起始日00:00包含，结束日次日00:00排除，包含结束日全部毫秒；拒绝倒序、未来和MySQL日期域外值 |
| size | 仅20、50、100、200 |
| cursor | 有值时1—2048字符；加密并认证，不接受明文UUID或直接offset |

目前Filter不包含status、channel、metric_profile、entity_type。未来公开入口须按合同明确拒绝不支持的筛选，不得静默忽略。

## 排序、截止与有界扫描

按created_at DESC、id DESC稳定排序，使用时间/UUID二元续页条件。首批截止取数据库UTC_TIMESTAMP(3)，只查created_at严格早于截止的事件，后续批保留原截止，避免正常后续追加混入当前扫描。排序时间相同也不重漏。前提是服务只追加且时间由数据库生成；本服务不提供修改/删除，不宣称数据库时钟回拨或绕过服务手工改历史后的强快照一致性。

一批SQL最多取201个候选，最多授权检查200个；多取1个只判断是否仍有候选。不足size且存在不可见候选时，Batch仍可能有continuation。调用者必须以continuation为空判定结束，不能以entries为空结束，也不能把scanned作为公开计数暴露。公开分页将来还需处理多批填充、统一预算和全局租户合并。

continuation使用独立SCOPE_AUDIT_QUERY_V1用途，与成员V1/V2及配置凭据密文隔离；AAD绑定目标、home、操作者，认证内容绑定筛选指纹、页大小、数据角色、home/target双权限版本、首批截止和最后扫描位置。篡改、换身份/目标/筛选/大小或权限版本变化均409，当前无功能权限403、目标不可见404。无密钥503。不将游标或筛选原文写日志；Batch/Entry.toString均隐藏内容。

查询不创建或修改业务记录。目录门闩在权限版本锁之前获取，保持与冻结写入相同的锁顺序。V018仅增加目标时间/UUID及历史操作者查询索引，可重复执行，不改变若依原菜单或回填历史字段。
