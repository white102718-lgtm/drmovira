# Python系统配置开发检查点

本记录只说明Python版本已经实现和实际测试的范围，不是系统配置整体或产品验收通过证明。旧Java证据不用于本记录。

## 实际实现

- 直接复用RuoYi-FastAPI真实登录、会话与动态菜单，增加ORBIT配置路由；现有Vue3/Element Plus页面连接独立Python测试服务。
- 已实现元数据、列表、详情、新建、修改、历史、只读测试七个接口。11类62字段与原扩展合同逐项核对，未知字段、重复JSON属性、条件必填、Unicode码点、枚举及数值范围分别校验。
- 配置权限要求当前有效SUPER_ADMIN数据角色、有效业务用户/团队/租户、系统读取与集成管理菜单授权；多功能角色取并集。当前数据库授权每次复验，客户端不能指定租户或操作人。
- AES-256-GCM凭据认证加密，AAD绑定租户/配置/字段，独立主密钥且拒绝复用JWT密钥。列表、详情、历史不返回明文或密文；保持/替换/清除操作分别处理。
- 保存具备版本CAS、幂等重放和敏感请求HMAC；业务数据、版本、审计、outbox和幂等响应同事务。审计冻结可信业务身份、团队和服务端请求ID，客户端请求ID不能覆盖。
- 前端同次保存意图在结果未知时保留幂等键；修改内容/目标/版本或明确拒绝后换键。只在组件内存保留不可导出临时HMAC密钥及摘要，不保留请求正文或写入浏览器持久存储；提交失败仍释放凭据输入，重输相同凭据可复用原意图。
- 历史按租户/配置/版本索引作倒序游标读取；只返回脱敏变更字段与状态摘要。配置列表当前仍为小规模配置集合读取，不代表大数据列表性能已验收。
- 前端文本校验与Python统一按NFC后Unicode码点计数，凭据不做trim/NFC变换。新增校验首轮曾导致Element Plus把KEEP误判为必填，已修正并补组件回归；全类型浏览器复验结果以最新回执为准。
- AI建议策略启用时，服务端复核默认提供商为本租户已启用的GPT/Claude配置；非法UUID、跨租户、停用及错误类型不能只靠页面选择器放行。
- 公开DTO按配置类型返回全部凭据槽位。清除或从未配置时返回configured=false及“未配置”，不能因存储JSON不含键而显示“无需云端凭据”；未知历史键不回显。
- 只读测试要求人工原因和If-Match；GPT/Claude查询模型，Meta应用/BM查询指定对象，固定官方域名、Bearer头、GET、禁止重定向/环境代理、响应限额及绝对超时。网络期间不持有数据库事务，落库前复验身份和版本；失败和BLOCKED不能转换为成功。

## 测试范围与证据

- `evidence/python-unit-boundaries.json`：登录适配、配置来源、字段白名单、JSON Pointer与凭据加密边界单测；实际数量以回执为准。
- `evidence/python-framework-integration.json`：独立MySQL13306、Redis16379/DB15、真实HTTP18083；包括审计/outbox故障回滚、相同幂等键并发、版本竞争、多角色、跨租户、即时撤权和角色降级，及探测中撤权/配置更新拒绝旧结果。平台HTTP传输使用生成凭据的fixture，不是平台真实认证通过。
- 同一运行器的`--browser`连接真实Python服务，在1440/1920/390视口验证登录、原菜单、GPT配置创建、保持凭据编辑、历史抽屉、摘要展开和内部横向滚动，以及只读弹窗取消不改版本、确认后写入结果。扩展至11类62字段默认值、密钥替换与编辑保持，并检查清除凭据返回检查/确认保存；是否通过以最新回执为准。截图目录为工作区`.runtime/python-browser-it`。
- 浏览器保存故障注入先用真实HTTP使后端提交，再丢弃响应，不伪造成功业务响应；重新输入相同凭据后断言幂等键不变、返回原配置ID且列表无重复。JSON/网关及网络错误只显示安全恢复说明。
- `evidence/python-frontend-components.json`记录组件/客户端/HMAC意图测试，API为fixture，与真实应用浏览器证据分开；类型检查、格式和生产构建属于工程验证，不冒充业务验收。
- `evidence/python-browser-configuration.json`保留最近一次三视口专项的实际时间和受测源码摘要；后续仅后端变更运行不带`--browser`时，不改写这份浏览器回执冒充重新验收。
- 首轮截图曾在抽屉滑入动画中截取；测试已增加几何位置条件，不能仅凭文本存在认定弹窗完整可见。首次权限复核发现USER角色放行遗漏，已收紧，后续回执必须包含同Token降权拒绝场景。
