# 分析任务内部入队事务

## 已实现范围

`AnalysisJobStore.admitTrustedHit`仅供未来可信规则分发器调用，当前没有HTTP入口、调度器或模型Worker。调用者仍须从持久化规则、对象和命中记录建立租户及对象权限，不能把外部请求直接转换成TrustedHit。

事务使用READ_COMMITTED。共享锁读取同租户启用的分析策略和已只读验证的GPT/Claude提供商，仅查询公开设置和版本，不查询、解密或复制Token。事实包先经AnalysisInputGuard校验，覆盖策略版本后冻结为稳定JSON和SHA256；配置公开设置、提供商/策略ID及版本随任务保存。输入使用LONGTEXT及JSON_VALID约束，避免MySQL JSON规范化改变参与摘要的原串。后续编辑配置不会改写旧任务。

每个租户、规则、对象有独立行锁。相同命中、输入及配置版本重放返回原任务，不重复计数；重放身份改绑规则版本或slot返回409。全局/规则限制严格合并后，原子检查冷却和日次数，入队、次数扣减、generation递增、旧QUEUED/RUNNING代次失效及事件记录在同一事务提交。任一步失败全部回滚。旧代次事件保留，尚未实现旧模型回调与建议发布之间的竞态保护。

冷却按UTC实际经过秒数计算；日额度按实际入队时刻转换到规则ZoneId后的当地日期计数，不按调度slot名推算日期。数据库时间存UTC。规则时区和命中真实性仍需上游规则持久化与分发器校验。
