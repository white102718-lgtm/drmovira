## 重跑入口

后端：`.venv/bin/python -m pytest -q`。

前端：`NODE_OPTIONS=--no-experimental-webstorage node node_modules/vitest/vitest.mjs run --config vitest.config.ts --maxWorkers=1`，随后类型检查与构建。Node新版本自带webstorage与原JSDOM夹具有冲突，因此显式关闭该运行时实验项。

真实数据库使用原`tools/run_python_framework_checks.py`独立环境档，迁移至062并按顺序追加064–075，传入`--environment-live-only --include-meta-connection-checks --include-meta-pipeline-checks`。需先准备独立本机MySQL和Redis，不连接生产库。附加`--environment-internal-browser`等待具名页面验收回执。不得仅以页面可达写PASS。
