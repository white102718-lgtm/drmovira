## CSRF、幂等与输入校验

GET csrf在当前读取权限下签发AES-GCM令牌，AAD绑定租户/会话UUID/用户及独立用途；不返回JWT、会话UUID或主密钥。POST要求16—255字符X-CSRF-Token，验证当前会话绑定与固定协议值。换会话、截断、伪造或无效令牌403 CSRF_INVALID；主密钥未配置503，不降级。有效性依赖若依会话，续期保持同会话可用，退出/过期由Redis会话阻断。

Idempotency-Key严格16—128个可打印ASCII，逐字节保留，不转换UUID。V011将request_key升级为VARBINARY(128)，区分大小写及空格；已有UUID键保留。相同tenant/actor/key及规范请求重放首份快照，payload不同409 IDEMPOTENCY_CONFLICT。范围/成员/权限版本/幂等头在同一事务内提交或回滚。旧快照发生授权变化后不因重放重新绑定，客户端需新请求键重新冻结。

必需请求头缺失或重复400。JSON重复字段/尾随JSON/未知字段/缺少必要字段400，模式、UUID、过滤器或数量业务无效422。只允许原ScopeRequest结构；冻结来源字段、actor及tenant注入都不接受。成员查询参数重复400、未知参数400；原通用参数status/date_from/date_to/operator_user_id/channel_id/metric_profile_id/entity_type不支持对冻结成员再过滤，明确422 UNSUPPORTED_FILTER，不静默忽略。
