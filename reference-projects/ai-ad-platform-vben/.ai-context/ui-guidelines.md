# AdPulse 前端 UI 强制规范

本文件是 AdPulse 前端 UI 的唯一权威来源。修改页面、布局、公共组件或共享样式前必须完整阅读；其他文档只允许链接本文件，不得复制 UI 细则。工程验证的通用边界见 `engineering-workflow.md`。

## 1. 范围、基准与安全

- 覆盖一级、二级和隐藏业务页面，以及导航、页头、卡片、筛选器、表单、表格、分页、弹窗、抽屉、浮层、空状态、详情和操作区。
- UI 调整必须保留 API、字段、校验、权限、路由、数据转换、提交行为和业务流程。
- 新增页面先选择同模块、同类型的稳定页面为视觉基准；用户指定设计稿优先，其次沿用公共组件和 Ant Design Vue/Vben 设计语言，不创建第二套视觉体系。
- 同类缺陷出现在多个页面或共享基线中时，优先修复共享组件、共享配置或全局样式；无法安全共享时列出受影响页面并逐页修复、回归。
- 正式实现优先使用 Vben、Ant Design Vue、VXE、现有业务组件和适配器，不引入第二套组件库、深色模式或营销页式信息架构。

## 2. 主题、组件原生样式与状态

- 产品仅支持浅色模式；使用项目语义主题令牌、`ConfigProvider` 和 `plat/src/styles/ux-baseline.css`，保持浅白/浅灰表面、统一圆角、细边框和轻量单层阴影。
- 主题色仅用于主操作、链接、焦点和小面积强调。成功、警告、错误使用 Ant Design Vue 语义色；禁止硬编码蓝、绿、橙、紫或黑色作为普通选中背景。
- 主题色变化必须同步更新背景、文字、边框、图标、焦点环、选中状态及滚动条，不得残留旧主题色。滚动条实现同时覆盖 Firefox 与 WebKit，不得隐藏或破坏系统滚动。
- Ant Design Vue 组件必须保留官方结构、交互状态和内部视觉。主题、圆角、字号、控件高度和间距只通过根级 `ConfigProvider`、官方 token 和项目语义 token 统一控制。
- 根级语义固定为 `componentSize="middle"`，不得启用 `compactAlgorithm` 或在页面建立第二套密度算法。
- 禁止使用 `.ant-*`、`:deep(.ant-*)`、依赖 Ant 内部 DOM 的选择器、固定高度、内联高度、`h-*` 或 `min-h-*` 改写控件颜色、圆角、高度、内边距、字号、阴影和状态。
- Button、Input、InputNumber、Select、Cascader、DatePicker、TimePicker、Radio、Table、Pagination、Tabs、Steps、Card、Spin 等密度型组件不得固定 `size="small|middle|large"`；共享组件未收到明确业务尺寸时必须继承根级配置。
- `Space` 间距、Avatar/图片像素、Progress 业务宽度和图表尺寸可保留，但不得借此修改 Ant 控件本体。
- 确因组件能力限制必须触及 Ant 内部结构时，先说明影响范围并取得用户明确确认。
- 默认、悬停、按下、选中、焦点、禁用、加载、错误、空数据和无权限状态必须清晰，不得只依靠颜色。普通文本至少满足 WCAG AA 对比度。

## 3. 页面大小、布局、卡片与对齐

- 五档页面大小统一读取 `plat/src/constants/ui-scale.ts`：控件高度 `24 / 28 / 32 / 36 / 40px`，字号 `12 / 13 / 14 / 15 / 16px`，普通圆角 `7 / 8 / 9 / 10 / 11px`，卡片及浮层圆角 `10 / 11 / 12 / 13 / 14px`；中等档对应 Ant Design Vue `middle` 基线。
- 页面大小必须统一驱动页头、侧栏、标签栏、菜单、卡片、图标、标题、表格、弹窗和抽屉。移动端仍须保留足够点击区域。
- 关联控件通常间隔 `8px`；页面外层、卡片内容和并列卡片通常使用 `16px`；独立模块间使用 `24px`。紧凑档只通过共享令牌缩放。
- 页面主要内容必须位于卡片或统一表面容器中；除全屏画布、沉浸式编辑器等明确场景外，页签、筛选、操作栏、表单、列表、表格、分页和空状态不得裸露在页面背景上。
- 卡片首层内容使用共享 `--adpulse-card-padding` 保留四向内边距。页面 gutter 不得替代卡片 padding；卡片与页签内容不得重复叠加同类内边距。
- 卡片内的页签导航、筛选、操作区和正文共享左侧起始线；仅分隔线或设计确认的通栏背景可延伸到内容边界。
- 页面卡片、部门树、表格正文等主要内容区域保持白色；VXE 表头使用中性浅灰，工具栏和分页器透明并透出外层白色卡片。
- 登录输入框在空值、聚焦、错误和浏览器自动填充时保持白色；左侧折叠菜单默认透明，悬停和选中必须有明确反馈。
- 卡片标题/工具栏与后续表格、表单或空状态之间固定保留 `16px`，优先使用 `gap-4` 或 `space-y-4`，不得依赖子组件 padding 制造间隔。
- 桌面端单行页头或工具栏的返回入口、标题、步骤和操作组使用同一个 `align-items: center` 中心线；窄屏换行时才允许切换顶部对齐，不用局部 padding、行高或 transform 补偿。
- “图标 + 文字”使用共享 `flex/inline-flex` 与 `align-items: center`；图标不可收缩，不依赖 SVG 基线、字符空格、`vertical-align`、`margin-top` 或 transform 补偿。
- 图标统一使用项目现有 Lucide 或 Iconify，不用装饰性 emoji 代替功能图标。保持一个明确主操作，低频操作收入“更多”。
- 页面根容器不得产生非预期横向滚动；宽内容只在所属视口内部滚动。

## 4. 表单与筛选

- 表单和列表筛选标签默认位于控件左侧、单行右对齐并垂直居中；窄屏统一切到控件上方左对齐。桌面端纵向标签必须有明确设计依据和布局标识。
- 同一表单按当前最长可见标签的实际文字宽度统一标签列，并增加约 `8–12px` 安全余量；使用共享最小/最大值约束，动态字段、语言或页面大小变化时重新计算。
- 标签必须完整显示，禁止裁切、遮挡、截断或省略。标签右边缘、控件起始线和换行后下一行控件起始线必须对齐。
- 输入框、选择器、日期/时间、数字输入和文本域占满控件区域；单选、复选和多选组按内容宽度展示。
- 筛选字段和搜索/重置按钮组位于同一个 `flex + flex-wrap` 容器；字段占位必须包含标签宽度、间距和控件宽度。普通字段使用共享 `220px` 布局宽度，空间不足时按完整字段自然换行。
- 日期范围等复合控件不得被相邻字段或按钮覆盖；操作按钮组不可拆分、不可压缩，剩余空间不足时整组换行。
- 筛选栏 `Textarea` 默认单行并继承当前页面大小的原生控件高度；允许粘贴换行并在内部滚动。只有明确需要直接展示多行时，才可独占一行或进入展开区。
- 列表筛选控件使用与业务含义对应的语义图标；默认下拉箭头、清除按钮不算筛选图标。搜索和重置按钮保留文字并分别使用搜索、重置/刷新图标。
- 统一复用 `ux-filter-form`、`ux-filter-field`、`ux-filter-actions` 和共享标签测量机制；禁止散落冲突的 Row/Col、grid、`labelWidth` 或页面专属像素补丁。
- 表单必须有可见标签、必填标识、就近帮助/错误文字、清晰键盘焦点；异步提交期间禁用重复提交并显示加载状态。

## 5. 表格尺寸、高度与滚动

- 所有列表和表格的表头、数据列及操作列统一左对齐；数字、金额、状态和短操作也不得单独右对齐或居中。
- 新建或可迁移表格优先使用 Vben/VXE 和共享适配器。表头、行高、单元格内边距和字号读取五档页面大小令牌；中等档表头 `40px`、行高 `44px`、横向内边距 `12px`。
- 页面内容区、卡片和表格容器建立连续纵向 flex 高度链，所有需收缩的中间层设置 `min-height: 0`；仅实际表格视口使用 `flex: 1 1 auto` 和 `overflow: auto`。
- 表格占满可用剩余高度并保留共享最小高度。空/少数据时不得缩成短条；长内容在表格内部滚动并固定表头，分页器、横向滚动条和底部操作始终可访问。
- 固定高度或最小高度只由实际内容视口一层负责。外层卡片、弹窗正文和包装器只建立高度链，不重复设置高度、占位或隐藏分页空间。
- 表格高度只根据稳定父容器可用高度计算；尺寸、视口、页头、筛选或分页变化时，可由共享 `ResizeObserver`/布局工具在下一帧重算一次。
- 禁止观察并反向设置同一子元素高度、按当前高度累加、递归定时器或无上限 watcher。卸载、失活或容器替换时清理 observer、事件和动画帧。
- Ant Design Vue `Tabs/TabPane` 不得直接包裹依赖父级 `height: 100%` 的 Page、卡片或 VXE Grid。全高页签由 Ant Tabs 只承载原生导航，项目级兄弟内容容器负责确定剩余高度、`flex: 1`、`min-height: 0` 和滚动视口。
- 不得用 Ant 内部选择器、视口高度减法、动态累加高度、递归观察器或祖先 `overflow: hidden` 掩盖溢出和循环增长。
- 宽表只在自身视口横向滚动。固定列及各状态背景必须不透明，层叠和边界阴影正确，不得透出或覆盖非固定列文字。
- 移动端可改用卡片或分段展示，但必须保留数据含义、选择、操作和分页能力。

## 6. 表格操作列

- 可用操作不超过 2 个时直接展示；超过 2 个时只展示最高频/主操作和一个“更多”入口，其余全部收入菜单，禁止平铺 3 个及以上操作。
- 菜单必须保持原权限、显示条件、禁用/加载状态、二次确认、参数和执行顺序。危险操作放末尾并使用语义危险色。
- 主操作与“更多”使用共享样式，保持单行、固定间距和键盘可访问；列宽按两个入口稳定设置，不随行内容抖动或换行。

## 7. 弹窗、抽屉与浮层

- Modal 使用共享固定高度，Drawer 保持固定视口高度；标题和底部操作固定可见，仅正文区域内部纵向滚动。页面不得重复定义高度和滚动规则。
- Select、TreeSelect、Cascader、AutoComplete、DatePicker、RangePicker、TimePicker、Dropdown、Popover、Tooltip、Mentions 等 Portal/Teleport 浮层采用统一滚动跟随策略。
- 根级 `ConfigProvider.getPopupContainer` 从触发控件向上选择最近的真实滚动祖先；复杂区域可使用 `[data-popup-scroll-host]`，找不到局部滚动上下文时才回退 `document.body`。
- 禁止把普通父节点、表格 `td`、Vben 主内容节点或 `document.body` 作为未经几何验证的固定宿主；禁止仅提高 `z-index`、强制 `overflow: visible` 或固定定位掩盖坐标系和裁切问题。
- 浮层展开后滚动页面、卡片、表格、Modal 或 Drawer 时，浮层必须与触发器同步移动；无法可靠跟随时在所属容器开始滚动后关闭。
- Modal、Drawer 和全屏预览挂载到应用级浮层根节点；二级浮层继承共享策略。确需局部覆盖时使用最小范围的 `ConfigProvider` 或显式宿主，并检查祖先 `overflow`、`transform`、`filter` 和 `contain`。
- 固定操作列等 sticky 触发器不得把浮层挂到横向滚动的表格视口；使用可靠外层宿主，并在内层滚动时关闭浮层。

## 8. 可访问性与文案

- 图标按钮提供 `aria-label`、Tooltip 或可见文字；图片提供有效 `alt`，纯装饰图片使用空 `alt`。
- 键盘可到达并操作主要交互，不移除默认焦点而不提供替代样式。
- 危险操作说明影响范围并在必要时二次确认；成功提示简短，错误提示说明原因和下一步。
- 同一业务对象和动作在不同页面使用一致文案，状态不得只用红绿颜色区分。

## 9. UI 工作流与验证

- 页面 UI 的新建、修改、重构、修复、审查和视觉验收同时使用 `impeccable` 与 `design-taste-frontend`。前者采用后台产品的 Operate 工作流，后者用于设计意图、现状审计和 anti-slop 检查；营销页规则不得机械套用到后台页面。
- 两个 skill 与本文件冲突时，以用户当前要求、本文件和现有技术栈为准；不得因示例引入 React、另一套设计系统、深色模式或未安装依赖。
- 完成后执行与范围匹配的格式、语法、类型、针对性 Lint 和 `git diff --check`；通用测试范围遵循 `engineering-workflow.md`。
- 文案、颜色或单个间距等低风险改动，在用户明确要求浏览器验收时，只需在当前页面做一次聚焦 Playwright 确认；结果清晰时不扩展全流程或多断点。
- 对齐、重叠、裁切、遮挡、固定高度、表格滚动、浮层定位、响应式、共享组件或全局样式属于高风险 UI；修改后必须使用 Playwright 在用户实际页面验证，并在刷新后复验。默认抽样当前视口和一个最相关风险断点。
- 用户要求全局检查或变更共享 UI 基线时，覆盖代表性一级/二级页面、五档页面大小、筛选换行、空/长表滚动、固定列、浮层、Modal/Drawer、主题色和卡片边界，不机械遍历无关页面。
- 几何验收读取目标及必要父容器的 `getBoundingClientRect()` 和关键计算样式：卡片分区间距为 `16px`；工具栏首层分组、图标与文字中心偏差不超过 `1px`；标签完全位于容器内；相邻筛选项交叠面积为 `0`；无非预期横向溢出。
- 表格验收同时覆盖空数据和长内容，确认滚动位置可改变、分页/滚动条/底部操作在所属容器和浏览器可视范围内。全高页签连续采样 Page、内容宿主、Grid 和表体高度至少 2 秒，切换页签及刷新后高度不得持续增长。
- 浮层验收实际打开浮层并滚动真实容器；记录触发器与浮层滚动前后的矩形。两者 `top/left` 位移应一致，或滚动后浮层关闭；同时确认未被页面、卡片、表格、Modal 或 Drawer 裁切。
- 验证后恢复用户原有页面大小和主题色状态，并记录操作路径、关键断言和可复现证据。
