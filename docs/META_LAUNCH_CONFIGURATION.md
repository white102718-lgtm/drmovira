# Meta 计划与草稿配置优化

日期：2026-11-12。依据用户《创建广告结构 (1).jpg》及已确认的舒适版纵向交互。

## 页面

进入投放管理 → 计划与草稿 → 新建服务器草稿／编辑草稿。账户、系列、广告组、广告上下排列，顶部提供定位导航；每层支持切换、新增、独立复制与删除，底部固定保存和当前配置预览。复制及删除同步处理逐账户身份引用。

高级设置按需要展开。原计划名称、负责人、渠道、身份、素材池、模板、保存恢复、版本控制和执行权限继续保留。预览包含尚未保存的更改，但不自动保存或发布。

## 配置覆盖

| 层级 | 本轮补充 |
| --- | --- |
| 系列 | 销售／潜客／应用推广，系列花费限额，CBO 开关，日／总预算，数量价值／费用目标／ROAS／竞价上限 |
| 广告组转化 | 网站／应用、成效目标、购物／加购／注册／潜客／订阅事件、点击 1／7 天与浏览无／1 天、展示计费 |
| 广告组受众 | 普通／Advantage、地区包含与排除、18—65+、性别、语言、自定义受众排除 |
| 广告组版位设备 | 自动／手动、多平台版位、两套内容库存选项、移动／桌面、Android／iOS 型号包含排除与版本上下限 |
| 广告 | 单图视频／轮播、排期、四种中文 CTA；原标题正文描述链接参数保留；轮播从已选素材池选择 |

## 默认值与必填信息

新配置默认竞拍、销售、ABO、最高数量或价值、网站转化量最大化、展示计费、普通受众、18—65+、不限性别与语言、自动版位、所有设备、标准库存、单图视频、立即订购、创建后暂停。这是 ORBIT 产品默认选择，不是宣称 Meta 所有账户的统一默认。

真实账户、地区、金额、主页／像素／应用资源和素材必须由操作者选择，不编造。旧草稿加载不会自动补写新字段。应用推广使用应用安装目标；保存不删除原有不兼容值，而是提示具体位置。

## 校验与执行边界

- 同系列组的成效目标一致；CBO 下转化事件一致；价值优化只能配合销售与购物；购买／潜客事件按目标约束。
- 系列与组预算不可并存；金额使用十进制字符串；反转日期、设备版本、地区包含排除重叠、空手动版位等会拒绝保存。
- 新字段经原草稿与模板保存回读，新增嵌套结构为精确类型，不接受任意 JSON。
- **本轮新增高级配置尚未接通对应广告执行适配。** 页面明确提示；预检、冻结与执行入口返回带字段位置的 `META_CONFIGURATION_UNAVAILABLE`，不会忽略新字段按旧默认投放。现有 Meta 读取授权不授予广告创建权限。
- 本轮不执行任何真实广告创建、启用或预算变更。独立能力接入及真实 Meta 创建验收仍是后续工作。

后端首次全量 6,362 项通过；随后修复网站目标误用 APP_INSTALLS 的对称校验，145 项相关回归通过。前端全量及线上浏览器结果见同目录验收报告。构建、组件测试不代表真实 Meta 广告执行通过。
