# 创建广告原型对齐与验收

来源：用户指定 `outputs/ORBIT_AntDesign_修订版/ORBIT_AntDesign_原型.html` 内自动化投放 → 创建投放。原文件未修改。

## 实现

- 菜单、页面标题与原“计划与草稿”页签统一为“创建广告”。路由保持 `/orbit/launch`。
- 默认进入页面内编辑，取代侧边抽屉；六段顺序：选择账户、广告系列、广告组、广告、组合与素材、确认执行。
- 账户搜索、只看已选、批选、负责人、账户状态/授权/余额/主页像素；渠道位于系列区域。未知余额显示 —。
- 系列/组/广告独立页签与新增/复制/删除；复制父级同时复制后代并重新分配ID、继承身份关联。删除须确认且至少保留一份。
- 系列目标、竞拍、CBO/ABO预算归属、单日/总预算、结束时间、竞价策略、标准投放、限额；组地区/年龄/预算/版位，更多配置折叠定向、排期、归因；广告名称/标题/正文/落地页/CTA/素材类型。
- 份数移至组合区，各层乘积计数；金额用整数微单位求和，按币种与周期分开。账户改为其他币种时明确确认预算币种，数值不作汇率换算；不同币种账户不可混选。
- 素材弹窗保留标签、分类、按广告数选择及原指标列；没有指标汇总时显示未知，绝不使用原型演示数据。按不重复/允许重复条件校验素材数量。
- 底部统一预览、保存为模板、保存草稿、确认创建。保存及重试仍使用现有版本/幂等/未知状态保护；预检、素材分配与执行进入现有真实服务流程，依赖不可用时禁用。
- 旧高级字段保留在原草稿中，可查看全部已保存字段；不会被原型布局静默删除。

## 正式系统与离线原型的区别

原型“模拟保存失败”“演示执行结果”不进入生产业务操作。API/MCP演示通道换为真实官方API/AdsPower通道。原型示例账户、素材、预算币种不伪装为用户真实数据。原型本地保存说明改为真实服务器保存。全局若依导航保持现有系统架构；对齐范围是创建广告业务页面。
